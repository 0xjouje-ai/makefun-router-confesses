A home Wi-Fi router confesses why it died at the climax of the movie — in one line. The program writes the excuse to `/output/entry.txt`:

> Sorry — I peeked at the ending, gasped, and fainted. Some twists are too much even for a router.

## Run it

```sh
node main.ts
```

Then read `/output/entry.txt` — one line, 96 characters.
